# JDSG Knowledge Graph Shopping

This repository contains a starter Python project for building a knowledge graph focused on shopping-related data.

## Project goals
- Provide a simple Python entry point
- Keep the project structure easy to extend
- Support future data ingestion and graph modeling work

## Getting started
1. Create and activate a virtual environment if needed.
2. Install the project in editable mode:
   ```bash
   pip install -e .
   ```
3. Run the sample entry point:
   ```bash
   python main.py
   ```

## Project structure
- `main.py` - sample application entry point
- `pyproject.toml` - Python project configuration
- `docs/` - planning and design notes
